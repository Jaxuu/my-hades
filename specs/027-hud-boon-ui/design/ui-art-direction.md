## 1. 视觉身份与统一语言

### 1.1 一句话视觉主张

> **「以冥府石殿的冷石为骨、青铜为筋、羊皮纸为面，让每一件界面都像从世界美术里凿出来的器物——质地在边框，读数在面上，一眼可读。」**

界面与 M18 世界美术**同处一个物质世界**：世界用「暖角色 / 冷环境 + 明度阶梯」讲可读性，界面沿用同一套光与材质语汇（左上光源、石/铜/羊皮纸/暗影四材），使玩家在「打斗 → 三选一 → 死亡 → 回营」的完整循环里感受到**一以贯之的界面质感**（US5 / FR-040）。

### 1.2 与 M16 / M18 既有资产语言的衔接

| 维度 | M16 现状（`index.html` + `assets/art/ui/`） | M19 目标 | 衔接手段 |
|---|---|---|---|
| **框体机制** | 48×48 九宫格白描，`border-image-slice: 12` | **不变**——沿用同一九宫格几何 | HD 只是**提高线描密度与材质层次**，不换机制、不换 slice |
| **皮肤注入** | `--ui-*` 自定义属性，默认 `none` | **不变** | 新增槽位一律走同一注入路径（`applyUiSkin`） |
| **调色板** | `--ink #1a1622` · `--parchment #e8d9b8` · `--parchment-dim #b9a982` · `--stone #7f8aa3` · `--stone-dark #2a2f3d` · `--gold #ffcd4a` · `--blood #e23e4a` | **扩色不改色** | 品质三色从既有色相族派生（见 §2），不引入新色相族 |
| **明度关系** | 深底（`--shadow` / `--stone-dark`）+ 亮字（`--parchment`） | **沿用** M18「明度阶梯」精神 | 界面版：**底 ≤ 30% 明度、框 30–55%、字/读数 ≥ 70%** |
| **滤镜** | UI 纹理 `image-rendering: pixelated`（`nearest`） | **不变**——UI 不参与 `HD_WORLD_ART_IDS` | 新 UI 纹理一律 `nearest`，与世界 HD 的 `linear` 分治（`manifest.ts` 已如此切分） |
| **字体** | 系统字体栈，无 `@font-face` | **不变** | 字号/字重层级见 §9 |

### 1.3 材质基调（四材）

| 材质 | 语义 | 表现 | 色域（取自既有调色板） |
|---|---|---|---|
| **石（Stone）** | 承载面 / 背板 / 框体主骨 | 冷灰石纹、顶缘微高光、底缘压暗 | `--stone #7f8aa3` · `--stone-dark #2a2f3d` |
| **铜（Bronze）** | 分隔线 / 装饰角 / 「可操作」高光 | 暖金属描边、受光面偏亮 | `#c8a24a`（新增，金族派生） |
| **羊皮纸（Parchment）** | 文字 / 读数 | 暖白，永远最高对比 | `--parchment #e8d9b8` · `--parchment-dim #b9a982` |
| **暗影（Shadow）** | 底衬 / 遮罩 / 未激活 | 近黑，压住背景世界 | `--ink #1a1622` · `--shadow rgba(10,8,14,.72)` |

> **光照规则（统一，M18 V5 的界面版）**：所有框体**左上受光、右下压暗**；高光宽度 ≤ 1px（48 基准下），保证缩放到任意面板尺寸时仍读作「凿出的石头」而非「发光矩形」。

## 2. 品质色系统（Common 蓝 / Epic 紫 / Legendary 金）

品质是**纯外观**（spec 裁定 1 / FR-016 / FR-031）：仅决定卡片与列表行的外观，**不参与任何数值或随机**。

### 2.1 三色具体色值（hex）

| 品质 | 中文标签 | 基色 `--rarity-*` | 亮色 `--rarity-*-bright` | 暗色 `--rarity-*-deep` | 派生自 |
|---|---|---|---|---|---|
| **Common** | 普通 | **`#3f6ea8`** | `#7fb0e6` | `#1c3350` | 既有 `.reward-button` 边框 `#3f6ea8`（蓝族） |
| **Epic** | 史诗 | **`#8a5cd0`** | `#c9a4ff` | `#3d2a63` | 营地紫族 `#d8c8ff` / `#c9a4ff` |
| **Legendary** | 传说 | **`#ffcd4a`** | `#fff0b8` | `#8a6a1e` | 既有 `--gold #ffcd4a`（金族） |

> 三色**均从既有色相族派生**，不新增色相族——保证「同一个游戏」的观感延续（§1.2）。

### 2.2 材质差异（**不仅靠颜色** → 色觉障碍多通道编码）

> **硬要求**（spec Edge Case 末条 / SC-014：仅凭外观区分品质正确率 ≥ 90%）：**颜色只是六通道之一**，任意单通道被关闭（去色 / 小尺寸 / 色觉障碍）后，品质**仍可区分**。

| 通道 | Common（蓝） | Epic（紫） | Legendary（金） | DOM 钩子（供 QA 断言存在） |
|---|---|---|---|---|
| **① 边框纹样** | 单道细规则线 | **双道**规则线 + 四角**菱形刻口** | **三道**线 + 四角**月桂卷草** | `boon-rarity-<q>` 的框体图 |
| **② 角标（pips）** | 单点 `◆` | 双点 `◆◆` | 三点 + 星 `★★★` | `.boon-pips`（子元素数 1/2/3） |
| **③ 文字标签** | 常显中文 `普通` | 常显中文 `史诗` | 常显中文 `传说` | `.boon-rarity-tag`（`textContent`） |
| **④ 图标外框** | 直角方框 | 切角方框（八边形） | 切角方框 + **顶部冠冕刻口** | `.boon-icon-frame--square\|--cut\|--crown` |
| **⑤ 颜色（冗余）** | `#3f6ea8` 蓝 | `#8a5cd0` 紫 | `#ffcd4a` 金 | `--rarity-<q>`（§2.4 载体） |
| **⑥ 外发光 / 品质环** | 3px 环，无辉光 | 3px 环 + 1px 静态辉光 | 3px 环 + 2px 缓慢微光（`prefers-reduced-motion` 下关闭） | `box-shadow`（§2.4 ①） |

> **可区分性验收**：对界面施加 `filter: grayscale(1)`，仅凭 ②③④ 三通道，三品质仍两两可分（SC-014 的「去色仍可分」检验）。
> **非颜色线索必须可被 QA 断言「存在」**（对齐 QA 约束 4）：`.boon-rarity-tag` 文本 + `.boon-pips` 子元素数 + `.boon-icon-frame--*` 变体类，三者均以**类钩子暴露**，供 `ui_skin.test.ts` 追加 `it` 断言其**存在**（否则 SC-014 的色盲缓解只是口头承诺）。

### 2.3 三色两两可区分度论证（含对比度）

**对比度**（WCAG 2.1 相对亮度；卡片底衬取 `#14121c`，L≈0.0067）：

| 品质 | 相对亮度 L | 对卡片底衬对比度 | 对羊皮纸文字 `#e8d9b8` 对比度 |
|---|---|---|---|
| Common `#3f6ea8` | 0.150 | **3.54 : 1** ✅ ≥3:1（非文本 UI 组件） | 4.7 : 1 |
| Epic `#8a5cd0` | 0.176 | **3.99 : 1** ✅ ≥3:1 | 4.2 : 1 |
| Legendary `#ffcd4a` | 0.654 | **12.43 : 1** ✅ | 1.07 : 1 ⚠️（金 vs 羊皮纸**不可**互为前景/背景） |

**色相角**：Common ≈ **213°** · Epic ≈ **264°** · Legendary ≈ **43°**。

| 色对 | 色相差 | 亮度差 | 判定 |
|---|---|---|---|
| Common ↔ Epic | **51°**（最小） | 3.54 vs 3.99（接近） | **最难区分对** → 强制依赖 §2.2 的 ②③④ 通道 |
| Epic ↔ Legendary | 139° | 3.99 vs 12.43（大） | 易区分 |
| Common ↔ Legendary | 170° | 3.54 vs 12.43（大） | 最易区分 |

> **结论**：三色**亮度两两差距 ≥ 0.03、色相两两差距 ≥ 51°**，均达「肉眼可辨」；但 **Common↔Epic 亮度接近**，故规范**强制**二者在**边框纹样（单线 vs 双线）+ 角标（单点 vs 双点）+ 图标外框（直角 vs 切角）**三处不同——这正是多通道编码的存在理由，也是 SC-014 ≥90% 的保证。
>
> **⚠️ 金色与羊皮纸不可互为前景/背景**（对比 1.07:1）：`--gold` **只作描边/高光/角标**，**绝不用作正文文字底色**。正文永远羊皮纸色。

#### 2.3.1 像素可区分度（供 QA 截图采样定阈值 · SC-003 / SC-014）

**RGB 通道差与欧氏距离**（供 `quality-and-verification.md` §6.2 的「三色两两 ΔRGB > 阈值」判据直接引用）：

| 色对 | ΔR | ΔG | ΔB | **欧氏 ΔRGB** | 判定 |
|---|---|---|---|---|---|
| Common ↔ Epic | 75 | **18** | 40 | **86.9** | 可分（G 通道最接近，**勿用 min-channel 阈值**） |
| Epic ↔ Legendary | 117 | 113 | 134 | **210.7** | 易分 |
| Common ↔ Legendary | 192 | 95 | 94 | **233.9** | 最易分 |

> **给 QA 的阈值建议**：判据用**欧氏 ΔRGB ≥ 60**（或 **max-channel Δ ≥ 50**），**不得**用「逐通道最小值」（Common↔Epic 的 G 仅差 18，会误判）。三对欧氏距离最小 **86.9**，对 60 阈值有 1.4× 余量。
> 若采样受抗锯齿/边框纹理干扰，**回退判据 = 六通道编码**（§2.2）——即便像素色差逼近阈值，纹样 / 角标 / 中文标签 / 图标外框仍保证可分。

#### 2.3.2 CSS 变量声明纪律（对齐 `quality-and-verification.md` §1.2 T4/T6）

- 品质三色**新增**变量：`--rarity-common` / `--rarity-epic` / `--rarity-legendary`（+ 可选 `-bright` / `-deep`）。**只增不改**。
- **禁止修改** `--parchment` / `--gold` / `--blood` / `--stone-dark`（`text_readability.test.ts` T6 冻结其存在；本规格仅从这些色**派生**新色，不改其值）。
- **禁止新增任何 `--font-*` 变量**（T4 断言 `--font-(body|mono)` 栈**恰为 2 个**；新增会使计数变 3 而失败）。新 UI 文本一律 `font-family: var(--font-body)`。
- `#hud, #keys, #gold {` 规则块**保持连续同序**（T7 正则要求），MUST NOT 在三选择器之间插入新选择器。

### 2.4 品质色的载体（**规避 M16 border-image 陷阱** · 关键）

> **陷阱（与 M16「border-image 拉成黑条」同源）**：现有卡片用 `border-image-source: var(--ui-frame-reward-card)` 的 48px 白描九宫格。**当 `border-image-source` 非 `none` 时，浏览器根本不绘制 `border-color`**——若品质色只写在 `border-color` 上，会被白描框**完全盖住**，屏上采到的是近白，三色**根本区分不开**。

**规则：品质色 MUST NOT 仅依赖 `border-color`。** 品质色由**三层独立载体**承载，**至少前两层恒绘制、恒可采样**：

| # | 载体 | CSS | 是否受 border-image 影响 | 作用 |
|---|---|---|---|---|
| **① 外层品质环** | 卡片外围 3px 实心环 + 辉光 | `box-shadow: 0 0 0 3px var(--rarity-<q>), 0 0 14px var(--rarity-<q>-glow)` | **否**（绘制在 border box 之外） | **恒可见、可采样**——像素判据的主锚点 |
| **② 品质 chip 背景** | 品质标识块的实心底 | `background: var(--rarity-<q>)` | 否 | 实心色块（~40×18px），**最佳采样锚点** |
| **③ 每品质专属框体图** | 把品质色**烘进白描线**的九宫格 | `border-image-source: var(--ui-frame-boon-<q>)` | 是（但颜色已在图内） | 资产路径的丰富化（蓝/紫/金线描 + §2.2 纹样差异） |

- **资产缺失降级**：`--ui-frame-boon-<q>` = `none` ⇒ 无 border-image ⇒ **`border-color: var(--rarity-<q>)` 正常绘制**（实心品质边框）——即 ③ 缺失时 ① ② 仍在，品质色**永不消失**。
- **每品质框体图（③）可选**：若工期紧，可只交付 ①+②（纯 CSS 品质环 + chip），品质色**已可区分**；③ 仅提升质感。
- **`boon-rarity-{common|epic|legendary}` 类钩子**同时挂在这三层所在的元素上，供 QA 采样定位。

#### 2.4.1 可采样区域建议（供 QA 在 `production/m19-probe.mjs` 编码 · SC-003/SC-014）

| 判据 | (a) 采样元素 / 包围盒 | (b) 排除 | (c) 统计量 | (d) 阈值 |
|---|---|---|---|---|
| **品质边框色（主）** | `.boon-rarity-<q>` 卡片**外层 3px 品质环**（border box 外扩 3px 的环带） | 文字、图标内部、内层白描线 | **中位数 RGB** | 三色两两 **欧氏 ΔRGB ≥ 60** 且 **max-channel Δ ≥ 50**；各色对声明 hex 每通道 ±25 内 |
| **品质色（副/交叉验证）** | `.boon-rarity-tag` 品质 chip **背景块** | chip 内文字像素 | **中位数 RGB** | 同上 |
| **图标存在** | 图标区 **96×96** 包围盒（`.boon-icon`） | 卡片背景 | 颜色**方差** / 非背景色像素数 | 方差 > 卡片背景方差 × 2（或非背景像素 ≥ 15%） |
| **描述文本存在** | `.boon-desc` 行包围盒 | 图标/边框 | 非背景像素行数 | ≥ 1 行文本像素 |
| **材质 HUD 非纯文本** | `#hud-material` 包围盒 | 无 | 颜色方差 / 显著色簇数 | 方差 > 阈值（≥3 色簇） |
| **品质标签文本** | `.boon-rarity-tag` 的 `textContent` | — | 字面量 | ∈ {`普通`,`史诗`,`传说`} 且非空 |

> **采样纪律（对齐 QA §6.2）**：一律用**中位数**抗抗锯齿/纹理；**禁用逐通道最小值判据**（Common↔Epic 的 G 仅差 18）；**必须排除文字与图标内部**再采样边框。

## 3. HUD 三组件规格（生命 / 冲刺充能 / 金币）

**共同约定**：九宫格 `border-image-slice: 12` · `border-image-repeat: stretch` · `image-rendering: pixelated` · 常驻（FR-005）· 读数未变化时**不重建节点**（FR-006，仅写 `textContent` / 改 CSS 变量）。

> **元素归属（对齐 `quality-and-verification.md` §2.3 / FR-007「诊断块与新 HUD 明确分离」）**：
> - **`#hud`（冻结 id）= 既有诊断信息块**——语义与元素**保留不动**（可选：降为调试态），**MUST NOT** 与新 HUD 混为一物。
> - **材质化 HUD = 新容器**（建议 id `#hud-material`，**新增**，不替换冻结 id），承载生命条 + 冲刺环。
> - **`#gold`（冻结 id）= 材质化金币牌**——复用既有元素重皮，**读同一个钱包值、不产生第二份读数**（FR-007）。
> - 三者（诊断块 / 材质 HUD / 金币牌）读不同数据、视觉分离，`#hud` 仍满足 T7 的 `#hud, #keys, #gold {` 连续同序约束。

### 3.1 生命条（Health）

| 项 | 规格 |
|---|---|
| **容器** | `#hud-material`（新容器）内左上 · 宽 **220px**（可 `min-width` 自适应）· 高 **22px** |
| **九宫格** | 框体 `--ui-frame-health`（新增槽位）· `slice 12` · `border-width 10px` |
| **底槽（track）** | 内嵌 **200×10px** 凹槽，`--stone-dark #2a2f3d` + 1px 内阴影（读作「凹进去的石槽」） |
| **填充（fill）** | 内嵌条，宽 = `ratio × 100%`；顶缘 1px 高光、底缘 1px 压暗（受光一致） |
| **数值读数** | `HP {cur} / {max}` · 羊皮纸 `#e8d9b8` · **14px / 600** · `font-variant-numeric: tabular-nums` · 居中叠于槽上 |
| **比例刻度** | 每 **25%** 一道 1px 铜色分隔（`#c8a24a`，α 0.5）——数值之外的**第二比例表达**（FR-002） |

**三态**（阈值按 `ratio = cur / max`，并在数值/边框上做**冗余**编码）：

| 态 | 阈值 | 填充色 | 冗余线索 |
|---|---|---|---|
| **满 / 健康** | `ratio ≥ 0.66` | **苔绿 `#5bbf7a`**（顶缘高光 `#9fe8b4`） | 静态，无附加动效 |
| **中** | `0.33 ≤ ratio < 0.66` | **琥珀 `#e0a83a`** | 边框铜色略亮 |
| **濒危** | `ratio < 0.33` | **血 `#e23e4a`** | **2px 内发光脉动**（0.6s 周期，α 0.4→0.8）· 边框血光 · `prefers-reduced-motion` 下改为**静态**血边框（不闪） |

**边界**：`max = 0` ⇒ 显示 `0 / 0` + 中性空槽（**禁止除零 / 反向条**，spec Edge Case）；`cur = 0` ⇒ 空槽 + 濒危态，**不出现负宽**。

### 3.2 冲刺充能（Dash Charge）

| 项 | 规格 |
|---|---|

**三态**（冷却进度 `p = 1 - remaining / total`）：

| 态 | 条件 | 环色 | 中心符文 | 动效 |

## 5. 图标系统（**纯 CSS 字形 / 形状 · 不新增图标资产**）

> **用户裁定 U3（2026-10-03）**：**纯 CSS 占位，不新增图标资产**。`--ui-icon-boon-*`（5 个）与 `--ui-boon-placeholder` 槽位**全部取消**；图标改为**纯 CSS 字形 / 形状**——每个祝福一个**字形**（单字符），默认 `◆`，叠在**品质外框**内。

### 5.1 五个祝福的 CSS 字形 / 形状映射

> **可渲染性原则**：字形取自**系统字体栈必含的基本 Unicode 块**（几何图形 U+25A0–25FF / 箭头 U+2190–21FF / 杂项符号 U+2600–26FF / 拉丁补充 U+00A0–FF），**不依赖任何图标资产、不触发网络字体**（§9.6）。对字体覆盖不确定的字形，**同时提供纯 CSS 绘制形状**（`clip-path` / 渐变）作为**保证可渲染**的等价物——**形状是兜底，永远可渲染**。

| 祝福 id | **设计意图（画什么 / 形状语言）** | **主字形** | 码点 · 块 | **CSS 形状（保证可渲染兜底）** | 强调色 |
|---|---|---|---|---|---|
| `zeus_strike` | 雷电劈落：尖锐折线 + 中心放射 | `↯` | U+21AF · 箭头 | `clip-path: polygon(...)` 之字闪电 | 电青 `#7fb0e6` |
| `dionysus_strike` | 中毒：圆钝团簇 + 单滴垂落 | `☣` | U+2623 · 杂项符号 | CSS **液滴**：`border-radius: 50% 50% 50% 0; rotate(-45deg)` | 毒紫 `#9a6ae0` |
| `poseidon_dash` | 冲击波：同心环 + 水平扩散 | `◎` | U+25CE · 几何图形 | CSS **同心环**：`repeating-radial-gradient` 或双 `box-shadow` 环 | 海青 `#4fc3c8` |
| `hp_up` | 生命上限：饱满实心 + 上升 | `♥` | U+2665 · 杂项符号 | CSS **心形**：`clip-path` 或 `::before/::after` 双圆 + 方块 | 苔绿 `#5bbf7a` |
| `dash_up` | 冲刺冷却：速度线 + 环形计时 | `»` | U+00BB · 拉丁补充 | CSS **速度线**：3 条 `skewX` 渐变斜条 | 铜金 `#c8a24a` |
| **默认 / 兜底** | 未知 / 未声明 | **`◆`** | U+25C6 · 几何图形 | CSS **菱形**：`rotate(45deg)` 方块 | 品质基色（§2.1） |

- **默认字形 `◆`**：任何未声明 / 未知 id ⇒ 一律用 `◆`（几何图形块，几乎所有系统字体与 CJK 回退栈均含）。
- **着色**：字形用祝福**强调色**（表末列）；**品质外框**用品质色（§2.4）。
- **去色可分**：五者字形/形状两两不同（↯ 折线 / ☣ 滴 / ◎ 同心 / ♥ 心 / » 速度线），`grayscale(1)` 下仍可分（对齐 M18 V1「剪影优先」）。
- **⚠️ 无 emoji 呈现风险**：MUST NOT 用**带 emoji 呈现**的码点（如 `⚡` U+26A1）；字形容器 MUST 声明 `font-variant-emoji: text`（或 `text` 呈现），且**始终以 CSS 形状为最终兜底**——字体缺字时形状仍在。

### 5.2 「字形渲染不出 / 未知祝福」时的占位策略

**两级降级（永不空白、永不裂图、无需任何资产）**：

1. **首选**：主字形（§5.1）正常渲染 → 显示字形。
2. **兜底**：字形缺字（系统字体无该码点）/ 祝福未声明 / id 悬空 ⇒ **默认字形 `◆`**；若连 `◆` 也异常 ⇒ **纯 CSS 菱形形状**（`rotate(45deg)` 方块，100% 可渲染）。

> 关键：**图标外框（直角 / 切角 / 冠冕，§2.2 ④）与形状均由 CSS 绘制、不依赖任何资产**，故图标永不空白、永不裂图（FR-017 / FR-050 / SC-010）。

### 5.3 命名与钩子（**无资产**）

| 项 | 约定 |
|---|---|
| **资产** | **无**（U3 裁定）——不新增 `ui.boon.*` / `ui.boon.placeholder` 资产，**不占用体积预算** |
| **字形来源** | 表现层数据表 `boons.json` 的 `icon` 字段承载**字形令牌**（如 `"bolt"` / `"poison"` / …）或直接字符；渲染为 `.boon-icon` 元素内文本 |
| **DOM 钩子** | `.boon-icon`（字形容器）· `.boon-icon-frame--square\|--cut\|--crown`（品质外框）· `data-boon="<rewardId>"` |
| **消费** | DOM 文本 + CSS（**不进 Pixi 场景图**） |

> **⚠️ 对 QA 的影响（须转 quality-lead）**：`quality-and-verification.md` §2.4 S3 断言「每个 `icon` id ∈ `MANIFEST_IDS`（无悬空图标）」——**U3 后不再成立**：图标无资产 id，`icon` 字段改承载**字形令牌**。S3 的该断言需改为「`icon` 令牌 ∈ 已知字形集合（5 + 默认）」或删除；降级断言改为「未声明 icon ⇒ 返回默认字形 `◆`」。

| 非文本 UI 组件（品质边框 / 焦点环） | ≥ 3:1 | Common 3.54 · Epic 3.99 · Legendary 12.43 ✅ |
| **禁用态文字** | ≥ 4.5:1 | 禁用只降装饰对比，**文字仍达标** |

### 9.3 焦点环（键盘可达，FR-052 / SC-015）

```
outline: 3px solid var(--gold);
outline-offset: 2px;
box-shadow: 0 0 0 5px rgba(10,8,14,.9);   /* 金环在金色按钮上仍可见的内衬 */
```

- 沿用现有 `:focus-visible` 规则（`index.html` 已冻结 `outline: 3px`）。
- **金底按钮**（`.start-button` / `--gold` 面）额外加**深色内衬环**，防「金环压金底」不可见。

### 9.4 色觉障碍多通道（汇总）

见 §2.2：**边框纹样 + 角标 pips + 中文品质标签 + 图标外框 + 颜色 + 动效** 六通道冗余。**验收**：`grayscale(1)` 下三品质仍两两可分（SC-014）。

### 9.5 动效与降低动态

- 濒危脉动、传说微光、hover 位移一律受 **`prefers-reduced-motion: reduce`** 约束 → 关闭或降为静态。
- 禁止任何**闪烁频率 > 3Hz** 的动效（防光敏性癫痫）。

### 9.6 文本可读（既有冻结契约，不得回退）

- **无 `@font-face`**、**无字体文件扩展名引用**（`.woff/.woff2/.ttf/.otf/.eot`）。
- 字体栈必含 CJK 回退 `PingFang SC` / `Microsoft YaHei` / `Noto Sans CJK SC`，且以 `sans-serif` / `monospace` 收尾。
- 由 `tests/ui/text_readability.test.ts` 冻结（FR-051 / SC-011）。

## 10. 资产体积预算（估算参考）

> **用户裁定 U2（2026-10-03）**：**不设 UI 子预算** —— UI 仅受 **M18 全局预算**约束（单文件 **≤ 3 MiB** / 总量 **≤ 12 MiB**）。本节数字为**估算参考**，**不作为验收断言**。

### 10.1 预算口径（仅 M18 全局预算）

**强制预算**（`tests/assets/licenses.test.ts`，M18 重定）：单文件 **≤ 3 MiB** · 总量 **≤ 12 MiB** · 单图集像素 **≤ 4096²**（目标 ≤ 2048²）· 图集数 **≤ 12**。当前 UI 贴图合计 **≈ 22 KB**（`assets/art/LICENSES.md` §6）。**M19 不新增任何 UI 子预算断言**（U2）。

**M19 UI 增量估算（参考）**：

| 类别 | 形态 | 数量 | 单件估算 | 小计 |
|---|---|---|---|---|
| 九宫格框体（HUD 生命框 / 冲刺环框 / 金币板 / 三套品质卡片框 / 状态面板框 / 三覆盖层框） | 48×48 单帧 PNG（`border-image`） | ~12 | ~2–4 KB | **~36 KB** |
| 品质角标 / 分隔线（可选，亦可纯 CSS） | 小 PNG 或纯 CSS | ~4 | ~1 KB | **~4 KB** |
| **祝福图标** | **纯 CSS 字形 / 形状（U3）** | — | **0** | **0 KB** |
| **UI 增量合计（参考）** | — | — | — | **≈ 40 KB**（若全用纯 CSS 框体则为 **0**） |

### 10.2 结论（估算参考，非验收断言）

| 项 | 值 | 说明 |
|---|---|---|
| UI 增量（参考） | **≈ 40 KB**（或纯 CSS 时 **0**） | 现有 22 KB + 增量 ⇒ 合计 ≈ 62 KB |
| 全局预算占用 | **< 0.6 %**（62 KB / 12 MiB） | 世界 HD 图集 ≈ 612 KB 仍占主导 |
| 是否需调全局预算 | **否** | 沿用 `MAX_FILE_BYTES = 3 MiB` / `MAX_TOTAL_BYTES = 12 MiB`（SC-016 满足） |
| **UI 子预算** | **不设**（U2 裁定） | 仅 M18 全局预算约束；本节数字仅供估算 |

> **说明**：因 U3 取消图标资产、框体亦可纯 CSS，M19 UI 的**真实体积增量可能为 0**；无论如何均**远在全局预算内**。**不新增任何断言**（U2），避免过度约束。

### 10.3 每张图的形态（尺寸 / 九宫格 / 是否 sprite sheet）

| 资产类 | 形态 | 尺寸 | 九宫格 | 打包 |
|---|---|---|---|---|
| **框体**（panel / frame / overlay，**可选**——亦可纯 CSS） | 单帧 PNG，`border-image` 消费 | **48×48**（slice 12） | ✅ `border-image-slice: 12` | **不打包**（`border-image` 需单图） |
| **祝福图标** | **无资产**（U3）——纯 CSS 字形 / 形状 | — | ❌ | — |

> **纹理过滤**：若交付框体纹理，一律 **`nearest` + `image-rendering: pixelated`**——**不**加入 `HD_WORLD_ART_IDS`（`manifest.ts` 已把 `ui.` 排除在 `linear` 之外）。世界 HD 用 `linear`、UI 用 `nearest`，二者**分治**，M17 冻结断言零改动。
