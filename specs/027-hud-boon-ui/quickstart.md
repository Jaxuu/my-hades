## V4 · HUD 三组件（US1）

进入一局游戏，触发：受伤 / 冲刺 / 拾取金币。

| 观察 | 判据 |
|---|---|
| 生命 | 数值与比例随 `hp` 实时变化；`maxHp=0` 不除零；`hp=0` 呈濒危态 |
| 冲刺 | 冷却中显示进度；`cooldownRemaining=0` 显示「可用」 |
| 金币 | 显示当前 run 金币数；极值不溢出 |
| 常驻 | 任意 overlay 下 HUD 仍正确（SC-001） |
| 非文本 | 血条 / 冲刺 / 金币**不再**是纯文本读数 |

## V5 · 三选一卡片三要素（US2）

清空一间房间 → 弹出三选一面板。

**判据（逐卡核验）**：每卡同时具备 ① 品质颜色（蓝/紫/金）② 图标 ③ 数值化描述；三要素携带率 = 100%（SC-002）。品质与 `boons.json` 一致率 = 100%（SC-003）。

## V6 · 描述数值与逻辑层一致（US2 · 关键）

逐祝福核对卡面数值与逻辑层真实值：

| 祝福 | 期望卡面数值 | 逻辑层来源 |
|---|---|---|
| `zeus_strike` | 20 点雷电伤害 | `modifiers.json` damage |
| `poseidon_dash` | 5 点伤害 / 击退 40 | `modifiers.json` damage / knockbackForce |
| `dionysus_strike` | 每 0.5 秒每层 4 点 / 最多 5 层 | `POISON_STATUS_SPEC` |
| `hp_up` | 生命上限 +20 | `HP_UP_AMOUNT` |
| `dash_up` | 冲刺冷却 -10 帧 | `DASH_UP_COOLDOWN_REDUCTION` |

**判据**：一致率 = 100%（SC-004）。⚠️ 注意用户原示例写「30 点雷电伤害」，真实值是 **20** —— 以逻辑层为准。

## V7 · Tab 局内状态面板（US3）

| 生命周期 | 终局 / 营地 / 销毁后无残留 Tab 监听（FR-025） |
