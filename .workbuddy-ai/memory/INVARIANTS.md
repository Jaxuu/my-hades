## 5 里程碑不变量
**M0–M2**（harness / 角色控制 / 战斗几何）：`fixedDeltaSeconds = 1/fps`、`tickDurationMs = 1000/fps`（**不截断**）；`elapsedSeconds = totalTicks * fixedDeltaSeconds`（**乘法**，非浮点累加）⇒ 60 ticks 严格 `=== 1.0s`；**禁硬编码 16.67**。输入事件**绑定目标 tick**：`step()` 每步先 drain 当前 tick 输入 → 跑系统 → 时钟 +1；同 tick FIFO；非法 tick / 已过 tick 抛 `RangeError`，`tick = 0` 合法。Snapshot = 深拷贝 + 递归 `Object.freeze`，与实时 world **零引用共享**。ECS：类式组件 + World 以构造函数为键；`query`/`listEntities` 按 id 升序，`listComponents` 按类型名 UTF-16 码元序（**禁** `localeCompare`）。`SystemContext` 携带 `fixedDeltaSeconds`（系统一律按模拟步长积分）。摇杆语义 = `clampMagnitude(v, 1)`（**不是** `normalize`）。`Movement→Dash→State` 三连顺序不可换：Movement 按**上一 Tick 的状态**积分 ⇒ 15 Tick 冲刺恰对应 15 个位移 Tick；StateSystem 最后跑 ⇒ 无敌窗口与冲刺前段对齐、第 15 Tick 精确退出。冲刺方向锁 = `startDash` 把 `(cosθ, sinθ)` 写进 `VelocityComponent.directionVector`，**绝不覆写 `PlayerInputComponent`**；DASHING 分支只读该向量、不重算 facing。冷却自「冲刺开始」计 30 Tick（「先递减、后判 `=== 0`」）；**冲刺是上升沿**（`buttonDashJustPressed`），长按不再自动连冲。无敌窗口判据 `ticksInState < invulnerableTicks` ⇒ 时钟 `1..12` 真、`13..15` 假（⚠️「时钟 N vs tick N」错位：注入在 tick 0，时钟 N = 已处理完 tick `N-1`）。标签走自由函数（`addTag`/`removeTag`/`hasTag`），组件保持纯 POD。判定圆 = **独立实体**，生成时取一次世界坐标（**不跟随攻击者**），寿命以 `activeTicks` 计；圆相交用**平方距离**（`dx²+dy² < (r1+r2)²`）。**无敌帧消费契约 = 整体忽略**：`hasTag(Invulnerable)` 时既不结算伤害、**也不写入 `hitEntities`**（写入 ⇒ 该目标对本次攻击**永久免疫**）。`applyFreeze` 必须写 `hitstopTicks + 1`（`FreezeSystem` 在消费方**之前**自减）；`HITSTUN` 的 `ticksInState` 必须种 `1`（`CollisionSystem` 排在 `StateSystem` **之后** ⇒ 命中拍不计入）——**两处补偿方向相反不是不一致，是相位差**。`DashSystem` 门控收紧为仅 `IDLE`/`MOVING`（HITSTUN 不可被冲刺打断、ATTACKING 不可被取消），实现要点：**先无条件消费脉冲、再门控**（被拒的脉冲**丢弃**，绝不缓冲）。`spawnCombatant` 是玩家/敌人的**唯一**装配点（组件集相同、仅阵营不同）；`EnemySpawnOptions` 声明在 `spawn-helpers.ts`（`components` 层**不得**反向依赖 `prefabs`）；⚠️ `export type { X } from './y'` **不会**把名字带进本地作用域——工厂内部要用 `X` 必须同时 `import type`。
**M3–M5**：每 Tick 全量 `drain()`（Tick 边界 `size===0`）；防递归门 `sourceModifier!==null` **先于**持有者判定；注入圆 `activeTicks≥2`；反馈门控 `hitstop>0||knockback>0`；DoT 只走 `applyDamage`（无圆/`HitEvent`/顿帧/硬直/击退/无敌帧）。`AISystem` 零字段只写 `IntentComponent`；门控序 `isFrozen`→`HITSTUN` 不可交换；`attackRadius>sightRadius` 抛错；索敌升序+严格 `<`+粘性。`DeadTagComponent`=死亡唯一权威（只由 `DeathSystem` Tick 末挂载，幂等）；门控一律 `isDead`，**禁** `hp<=0` 重推导；门控序 死亡>冻结>硬直；`LifespanSystem` 不加死亡门。房间=`EncounterStateComponent` 全局单例；三态 `IN_PROGRESS/WAVE_CLEAR/ROOM_CLEARED`；`isWaveCleared` 对空 `false`；`nextSpawnTick` 绝对 Tick（-1=未排期）；`EncounterFactory.spawn` 不生成第一波⇒调用方至少 `step()`；Tick T 生成者首次行动 T+1。`client/` 唯一允许 DOM/PixiJS，单向只读；`PX_PER_UNIT=10`；`retired:Set` **不可删**（P0）；`fxLayer` 必须是 root 最后子节点；`syncWorld` alpha clamp `[0,1]`。
**M4 补充**：`AISystem` 必须排在 `FreezeSystem` **之后**（相位契约：冻结按自减后的值判定，否则敌人比玩家晚一拍恢复）；`attackRadius > sightRadius` 在装配期抛错。AI 的朝向锁定**只写 `IntentComponent.aimRadians`**，绝不直接写 `TransformComponent.facingRadians`（facing 只能有一个写入者）；`MovementSystem` **只在静止分支**应用它。AI 是 **opt-in**（`EnemyFactory.spawn` 默认**不挂** `AIControllerComponent`，显式传 `ai` 才挂）；`ai` 与 `hardwareInput` 互斥，同时给出抛 `RangeError`。顿帧 = **暂停（不吞帧）**、硬直 = **打断（作废计划）**，门控序 `isFrozen → HITSTUN` **不可交换**。进入前摇那一拍**不递减** `ticksRemaining` ⇒ 前摇恰 `windupTicks` 拍；冷却结束**只回决策态**（`CHASING`/`IDLE`），不直接进 `WINDUP`。`IDLE→CHASING` 的「发现」拍**只翻状态、不输出移动向量**（1 Tick 反应延迟），但 `IDLE` 的 `dist ≤ attackRadius` 分支**无**延迟。`wantsToAttack` 是单 Tick 脉冲且同拍被 `CombatActionSystem` 消费 ⇒ 断言它的探针必须插在 `AISystem` **正后方**（按名 `findIndex` 定位，**禁硬编码索引**）。`EncounterStateComponent.trackedEntityIds` 在 `ROOM_CLEARED` 时**保留**最后一波名单（空列表的含义是「本波尚未生成」；只有 `WAVE_CLEAR` 提升分支才清空）。⚠️ 死亡门控存在**冗余**（尸体常带 `FreezeComponent` ⇒ 冻结门顺手把它拦住），冗余本身是好事但会**掩盖测试空洞**：想独立断言某道门，必须构造**只可能由该门拦住**的对抗性场景（例：用 `hitstopTicks = 0` + `knockbackForce > 0` 的判定圆杀死目标，让尸体「有击退在飞但没冻结」，MovementSystem 的门才成为唯一防线）。
**表现层补充（M5）**：`PreviousTransformComponent` 是**渲染支撑组件**——只由 `TransformSnapshotSystem` 写、只由渲染层读，**任何玩法系统不得读写**，丢弃它不改变模拟结果；**惰性挂载**（首见实体以当前 Transform 播种，故 `spawnCombatant` 的组件契约无需改）。`syncWorld(world, alpha)` 的 `alpha` clamp `[0,1]`、**默认 `1`**（`alpha=1 ⇒ renderX = currX`，逐位等价 M5-T01，冻结测试的单参调用原样通过）；rotation 走 `shortestArcDelta`（值域 `[-π, π]` 两端都闭，`-π ≡ π`）。`GameLoop` 三条：**注入必须先于 `step`**（`inject` 对 `tick < sim.tick` 抛 `RangeError`）；**必须用 `sim.tickDurationMs`**；追帧上限（`steps === 5`）时**清空累加器**防螺旋死亡。alpha = 追帧 `while` **之后**的 `accumulatorMs / tickDurationMs`（clamp）。PixiJS v8：`await app.init({...})`、画布是 **`app.canvas`**（非 `app.view`）、`Graphics` 是链式 API（**无** `beginFill/drawCircle/endFill`）、`new Text({text,style})` 对象形式（位置参数形式已废弃会打警告）。⚠️ **纯 Node 下读 `.width`/`.height`/bounds 抛 `document is not defined`**（惰性文本测量需要 canvas）⇒ 跳字断言只能碰 `.text`/坐标/alpha/父子关系。⚠️ **假 `Application` 替身只有 `{stage, ticker}`，没有 `renderer` 也没有 `screen`** ⇒ 渲染层任何依赖它们的调用都会在测试里抛错，必须走可选访问 + 兜底。⚠️ `syncWorld(world, NaN)` 会**穿透** clamp（`Math.min(1, Math.max(0, NaN)) === NaN`）⇒ `container.x/y` 变 `NaN`、实体静默消失；`±Infinity` 被正常 clamp，**只有 `NaN` 穿透**（当前调用链不可达，spec 10 §10 已登记，未修；M12-T02 的相机是**第二条**同源 NaN 通路，见 M12-T02 段）。
**M6**：`Random`(Mulberry32) 挂 `World.rng`，seed 透传（默认 `0x12345678`），只读不重播种（ADR-004），不进 Snapshot；`nextFloat` 右开/`nextInt` 双端闭/`sample` 无放回/`pick([])` 抛。`pendingRewards:string[]|null` ⟺ `ROOM_CLEARED`；读侧唯一入口 `findRewardDraft`；选择走 `InputQueue(SelectRewardEvent)`，UI 只发 id，`RewardSystem` 用 `pending.includes` 复校验。`applyDamageWithArmor`=命中结算唯一入口；`absorbed=min(current,damage)`、`spill=damage-absorbed` 守恒；`current` 只减不增，`0` 永久破损；霸体只豁免 `HITSTUN`+击退，**绝不豁免顿帧**；DoT 不走护甲。`DashEvent` 第三总线 `DashSystem`(idx6)→`ModifierSystem`(idx11) 同 Tick，**只在真进入 `DASHING` 时发**。
**M7**：`resolveCircleAABB` 纯函数（贴边不算碰；盒内取最近面，平手 `-x,+x,-y,+y`）。`WallComponent`(AABB，**不挂 Transform**)。`MovementSystem` 三相 `integrate`/`integrateKinematic`（`ProjectileComponent` 自驱，**不加死亡/冻结门**）/`resolveWalls`；解算集=`Transform`+`Velocity`+圆半径（先 `Hurtbox` 后 `Hitbox`），不查冻结/硬直，查 `isDead`，逐墙顺序推出（实体 id×墙 id 升序）。**撞墙四条件** `pushed`∧`HITSTUN`∧`Knockback`≠0∧`dot(push,kb)<0`；三写 `applyDamageWithArmor(12)`+`ticksInState=0`+`kb.velocity=(0,0)`；**不顿帧**。`spawnProjectile` 唯一装配点；`destroyOnHit`⇒写完后 `destroyEntity`+`break`。
**M8**：`HazardComponent` 只挂 `Transform`+自身（阵营存 `faction`）；倒计时**先判后减**（`delayTicks=N`⇒N 拍预警+第 N+1 拍爆）；`HazardSystem` 两相位 A 播种→B 倒计时**不可交换**，**不读 `isFrozen`**；爆破圆 `activeTicks=1`、`destroyOnHit=false`、`hitstop=0`+`knockback=10`，`ownerEntityId`=Hazard 自身；落点=施法者 AI 目标坐标（无则自身）；`wantsToHazard` 第四脉冲，**消费方查询必须全员**（`Intent`+`Transform`+`Faction`）。`GameStateComponent` 全局单例+**opt-in**（缺失即 `PLAYING`），`GameStateFactory.spawn` 唯一装配点；玩家判据=`PlayerInputComponent`；`RUN_FAILED` **只加两道门**（`PlayerControllerSystem.suppressed`／`EncounterSystem` 首行 `return`），各需**独立**断言，**不暂停 `step()`**。`restartRun(newSeed?)` 六步 `clearEntities→reseed→input.clear→scheduler.reset→clock.reset→runSetup`；**`clearEntities` 绝不重置 `nextId`（P0）**；`reset?()` 只 `DeathSystem`/`ModifierSystem` 实现。
**M9**：拾取物=**恰好** `Transform`+`PickupComponent`；判定半径和=`pickup.radius+collector.hurtbox.radius`，严格 `<`；**消费 `markDead`，移除交 `LifespanSystem`**。掉落表=实体 spec 的一部分（`loot` opt-in），**装配期** `resolveLootDrops` 校验（**空表抛错**）。钱包 `InventoryComponent` 挂 `hardwareInput` 分支；**装备不进钱包**。`GameStatus` 加**兄弟态 `RUN_WON`**；**`isRunOver=FAILED||WON` 是唯一「不再决策」谓词**；**终房判据唯一 `isFinalRoom`**：`advance` 先判终房再滚三选一⇒**终房一次 PRNG 抽签都不消费**；`RewardSystem` 有结算侧孪生守卫。⚠️ **单房间配置=终房⇒清空即胜**；⚠️ 房间 k 波次=`基础+depth k 份复制`；`createView` 分类序 **pickup→hazard→hitbox→faction**。
**M10**：`assets/data/*.json` 唯一数值来源；`src/data/` 三层 `schemas.ts`／`DataManager`（静态注册表 `loadAll`）／`bundled.ts`（异步 Bootstrap，早于 `GameSimulator` 构造）。**加载期大声抛，运行时零校验**。`encounters.json`=**有序数组**，条目 `k` 必须 `depth===k`；波次只写敌人**类型 id**。`RawConfigTables.*` 可选且**「缺席 ≠ 空数组」**；**跨表校验只能在 `loadAll`**；`getEncounterWaves(depth)` **超界循环 `depth%n`**。下降收敛到 `descendEncounterRoom`（`roomWaves[i] ?? resolveEncounterWaves(depth)`）。**`src/` 零 `import.meta`**；HMR 只在 `client/bundled.ts`（Vite 入口必须**自己** import JSON 并 accept）。重载=`DataManager.loadAll`+`restartRun(sim.currentSeed)`（**同种子**）+`GameRenderer.reset()`（**≠ `destroy()`**）。失败**软着陆**（原子性保旧表）。
**M11**：`reflectVec2`=Householder `V-2(V·N)N`（内部归一化，零法线原样返回，纯函数/保长/保角/对合）；`dotVec2`。反弹=`resolveWalls` 后果分支（`destroyOnWall`∧`ProjectileComponent.bounceCount>0` ⇒ 扣额度+按**累积推力归一化**法线反射，**每实体每 Tick 只反射一次、禁 `while`**）；`bounceCount` 放 `ProjectileComponent`；`pierceCount`/`damageFalloff` 放 `HitboxComponent`。穿透=命中结算+反馈+`HitEvent`**之后**、`destroyOnHit`**之前**：`pierceCount>0` ⇒ 扣1、`damage*=(1-falloff)`、`continue`（衰减只作用于**后续**目标）。连环雷=`onExplodeConfigId`→原地再生成次级 Hazard 并**返回 id**；`advanceHazards` 改**工作队列排空**（子雷进当拍队列⇒引信当拍起算）；`MAX_HAZARD_CHAIN_PER_TICK=256`+`loadAll` 的 **DAG 环检测**。`ProjectileConfig` 全字段可选（缺省 `DEFAULT_CAST_*` 兜底）。
**M12**（关卡拓扑/Tilemap）：网格 JSON 一维或二维，**归一化成一维行主序**；格码 `0`地板/`1`墙/`2`玩家出生/`3`敌人刷新区；`RoomConfig` 只存 `{id,width,height,grid}`，派生量一律纯函数。**世界坐标契约**：格 `(col,row)` 占 `[col,col+1]×[row,row+1]`，中心 `(col+0.5,row+0.5)`，房间左上角格=世界原点；`1×1` 格 + 半径 `0.5` ⇒ 格中心出生**恰好相切四邻**（贴边不算碰⇒不被自己推挤）。`src/core/LevelLoader.ts` 是**唯一**地形→实体转换器（静态、无状态，只在房间边界调用，**不是管道段**）：`loadRoom`/`clearRoomEntities`/`resetPlayerPose`/`enterRoom`。`enterRoom` 顺序=契约：清旧→建新→导出出生点→重置玩家位姿→写 `enemySpawnPoints`（**先清后建**让新旧墙 id 不重叠）。清理集=**恰好** `{Wall, Hitbox, Hazard, Pickup}`（按 `HitboxComponent` 而非 `ProjectileComponent`；战斗单位只有 `Hurtbox`⇒不可能误伤）；**尸体不清理**（`死亡是状态不是删除` 的例外成本太高）。`descendEncounterRoom` **必须清空 `enemySpawnPoints`**（漏了只在「有拓扑→无拓扑」方向静默出错）。`resetPlayerPose` **必须同步 `PreviousTransformComponent`**（`TransformSnapshotSystem` idx0 已记下旧房间坐标⇒否则渲染跨图插值一帧）。出生点=`随机起点+确定性轮转`，**每波恰好 1 次抽签**（不重叠 / 流扰动是常数 / `depth` 复制体自动回绕）；**空池⇒早退且不抽签**（零回归的关键）。`roomIds:(string|undefined)[]` 与 `roomWaves` **同下标对齐**（不塞进 `roomWaves`——其形状被引用同一性钉死）；`roomId` 在 schema 中**可选**（出厂数据每间都写，跨表校验只在 `loadAll`）。`GameSimulator` **保持游戏无关**（不加 `initialRoomId`）：拓扑装配收敛到构造期 `runSetup`⇒`restartRun` 第 6 步必然重载房间 0。渲染静态层**惰性挂 `stage` 索引 0**（仅「世界至少一堵墙」时存在）⇒ `stage.children[0]===root`／`root.children[0]`=首个实体视图／`root.children[last]===fxLayer` 三条 M5 冻结契约零改动（⚠️ 其中 `stage.children[0]===root` 已被 **M12-T02** 的相机改写，见下）。
**M12-T02**（引擎优化 / 软碰撞 / 摄像机）：`LevelLoader.mergeWallRects` 贪心合并（**先横后纵 + `visited` 防重叠**，输出按矩形左上角行主序）⇒ `spawnWalls` 一墙一矩形，`resolveWalls` 从 `O(瓦片)` 降到 `O(矩形)`；**并集精确等价**（`Σ(宽×高) === wallTileCount` 且两两不重叠）⇒ 解算行为逐位不变（矩形边必落在原格线上，最近面不变）。`RoomLoadResult.wallCount` 语义 = **合并后矩形数**（不再是 `1` 的个数），**新增 `wallTileCount`** = 合并前瓦片数；两数一起才是「合并等价」的等式。`MovementSystem` 新增**第 3 相位** `separateBodies`（`integrate→integrateKinematic→separateBodies→resolveWalls`，**不新增管道段**——同实体物理相位挂 `MovementSystem` 尾部的既定落法）：目标集 `Transform`+`Velocity`+`Hurtbox`+`Faction`，**仅同阵营**、跳过 `isDead`、严格 `<` 才算重叠、位移**不乘 `fixedDeltaSeconds`**（位置修正 ≠ 速度积分）；完全重合用 `separationAngle(a,b)`（`Math.imul` 混合 + 16 槽，**零熵**，纯函数）。**顺序即契约**：分离先跑、墙体解算后跑 ⇒ 几何永远拥有最终发言权（分离不可能把身体推进墙里）。**分离不设冻结/硬直门**（与 `resolveWalls` 同属几何不变量；不对称处：墙解算下冻结体不会「新穿透」，而分离**能**推动冻结体——已登记为可接受取舍）。表现层场景图改为 **`stage → camera → { staticLayer(idx0), root }`**：`camera` 是 stage 唯一子节点、`root` 恒为 `camera` **最后**子节点（`root.children[0]`=首个实体视图、`root.children[last]`=`fxLayer` 两条**未变**）；`syncCamera` 读**插值后**的玩家视图坐标，`camera += (screen/2 − playerPx − camera) * CAMERA_LERP_FACTOR(0.2)`（从 `1e6` 偏移实测 155 帧达 `1e-9`、停在 ≈1 ULP）；跳字（世界坐标）随相机平移，HUD 留 DOM（天然屏幕固定）。⚠️ 假 `Application` 无 `screen` ⇒ 降级 `0`（目标 = `−playerPx`）；**渲染层绝不读 `app.renderer.*`**。⚠️ `syncWorld(world, NaN)` 会让 `camera.x/y` 也变 `NaN`（**第二条 NaN 通路**，与 M5 视图 NaN 同源，当前调用链不可达）。
**M13-T01**（局外成长 / 存档 / 营地）：`SaveState{darkness, unlockedUpgrades}` **不是组件、不进 `snapshot()`、`restartRun` 不重建**——它由 `GameSimulatorOptions.initialSaveState` **注入**，`sim.saveState` 返回**注入实例本身**（挂成组件就会被它必须存活的那个操作销毁）。`src/**` **禁接触任何存储介质**（ESLint AST 门）；介质只在 `client/SaveStore.ts`（`Storage | null`，**任何失败降级成空档、永不致命**，与数据层「畸形 JSON 必须中止启动」刻意相反）。`SaveState.toJSON()`/`from()` 是唯一序列化通道；`unlockedUpgrades` 按 UTF-16 码元**升序**（同进度 ⇒ 同字节）。**暗影是两本账**：局内写 `InventoryComponent.darkness`（Run 内、快照可见、随 Run 销毁），**唯一**跨界写点 `GameSimulator.enterHub()` → `bankRunDarkness`（入账 + **清零 Run 账本**，清零是幂等护栏：没有它营地进出两次就发两次钱）；`enterHub` 对**无 `GameStateComponent`** 的世界是严格 no-op（检查在入账**之前**，否则「转了营地」与「发了钱」会变成两个能互相矛盾的答案）。`GameStatus.HUB` **必须**进 `isRunOver`（`FAILED||WON||HUB`）——漏了会让营地**重新打开** `RUN_FAILED` 关掉的每道门（调度器在尸体上刷怪、拾取继续结算）；`PLAYING` 是唯一「未结束」状态；`HUB` 是**状态不是系统**⇒ **不新增管道段（仍 17 段，9 处管道钉桩 + 5 处段数钉桩零改动）**。局外天赋走 `assets/data/meta_upgrades.json` → `MetaUpgradeConfig{id,cost,type,value,label?}`，`type ∈ {MAX_HP, MOVE_SPEED, DASH_COOLDOWN_REDUCTION}`（**只收录落在玩家已有组件上的加成**；「额外冲刺次数」需先把冲刺改成充能制 ⇒ 明确排除）。`resolveMetaBonuses(ids)` → `MetaBonuses{maxHp,moveSpeed,dashCooldownReductionTicks}` **只在 `runSetup` 期跑一次**（解析成纯数字，`spawnCombatant` 内**零查表零抛错**——它被 `step()` 间接调用）；**加性是契约**（`{maxHp:50}` = 「多 50」），`hp` 默认跟随**加成后的** `maxHp`；未知 id saveState)`——**加性**，单参数 lambda 零改动。`purchaseMetaUpgrade(id)` **返回 bool 永不抛**（唯一调用方是 DOM 按钮），且**不校验是否在 HUB**（那道门天然存在于「只有营地 UI 提供购买」里，引擎里再写一遍是冗余第二真相）。`thick_skin` 发货价 **30**（任务书 §Task2 示例写 100 与 §Task4
