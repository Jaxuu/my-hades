⇒ 想让它**可被独立断言**，测试必须构造一个「带标签但 `hp > 0`」的实体——
正常玩法产不出来，但这恰好钉住了真正的契约：**门的键是标签，不是血量数字**（未来加治疗/复活时不会静默失效）。

### 关键发现 3：死亡门控的**冗余是好事，但会掩盖测试空洞**

- MovementSystem 的门**未被捕获**：因为尸体死时带着 `FreezeComponent`（`hitstopTicks+1`），
  而 FreezeSystem 跳过死物 ⇒ 计数永不递减 ⇒ `isFrozen` 恒真 ⇒ 冻结门顺手把尸体拦住了。
  **破法**：用 `hitstopTicks = 0, knockbackForce = 12` 的判定圆（纯击退、不结冰）杀死目标，
  尸体于是「有在飞击退但没冻结」，MovementSystem 的门成为唯一防线。

  ⇒ 用**对抗性探针**（手工给尸体写 `wantsToAttack` / `wantsToDash` / 手工挂 poison）独立钉住。

**最终 13 处变异全部被捕获**（3 道 Collision 门 + 9 个系统的死亡门 + DeathSystem 的重复事件守卫与意图中和）。

### 关键发现 2（P0 缺陷，已修）：尸体视图会被「复活」，死亡效果无限重播
**根因**：`createMissingViews` 只以 `world.query(TransformComponent)` 为依据建视图。但 M4-T02 铁律是
**尸体永不销毁**（spec 08 §4.4）⇒ 尸体仍 `isAlive`、仍有 `TransformComponent`
⇒ 死亡 FX 播完 `recycle` 删掉视图后，**下一帧立刻为这具尸体重建视图**，`syncTransforms` 又看到
`isDead` → `isDying = true` / `deathElapsedMs = 0` → FX 从头重播，周期 = `DEATH_FADE_MS`（400ms）**无限循环**。
表现：方块每 400ms 闪回一次，直接违反验收标准「打死方块后方块消失」。

**复现手法（值得复用）**：`pixi.js` 的**场景图对象（`Container` / `Graphics`）在 node 下可正常构造**，
不需要 jsdom、不需要真浏览器——只需给 `Application` 一个鸭子类型替身
`{ stage: new Container(), ticker: { deltaMS: 20, add(){}, remove(){} } }`，即可用真实 `GameSimulator` +
真实 `GameRenderer` 逐帧驱动并观测 `renderer.viewCount`。
缺陷签名极其清晰：`2,2,…,2,1,2,2,…,2,1`（每 20 帧 = 400ms/20ms 循环一次）。

**修法**：`GameRenderer` 引入 `private readonly retired = new Set<EntityId>()`，
`createMissingViews` 对退役 id `continue`；**只在「死亡 FX 播完」这条路径退役**
（`advanceDeaths` 里 `retired.add(id)` 再 `recycle`）。
**关键取舍**：`recycleDestroyed`（`destroyEntity`，如判定圆寿命耗尽）**不退役**——那条路径自纠正
（已销毁实体不再出现在 `query` 里），而万一将来 id 被复用，误退役会**永久隐藏一个合法实体**，是更糟的失败模式。
⇒ 该 `Set` 的安全性依赖 **`World.nextId` 单调递增、id 永不复用**这个不变式，注释里已写明。
修复后 60 帧序列收敛为 `2,…,2,1,1,1,…`。

### 关键发现 3：变异测试确认新防线是「钉子」而非冗余

### 工程要点
- **`vite` 被钉在 5.x**：不是随意选择——`vitest@2.1.8` 的 peerDependency 是 `vite ^5.0.0`，
  装 vite 8 会造成 peer 冲突。⇒ 未来升级 vitest 时才能一起升 vite。
- **`pixi.js` 是 8.21.0**，API 与 v7 差异极大：`await app.init({...})`、画布是 **`app.canvas`**（不是 `app.view`）、
  `Graphics` 是链式 API（`g.circle().fill().stroke()`，**没有** `beginFill/drawCircle/endFill`）。
- **根 `tsconfig.json` 不能塞 `client/`**（根 `lib` 只有 `ES2022`，无 DOM）；新建 `tsconfig.client.json`
  （`lib: [ES2022, DOM, DOM.Iterable]`，`noEmit`，strict 未关）+ `typecheck:client` 脚本。
- **`GameLoop` 时序**：累加真实 `deltaMS`，`while (acc >= sim.tickDurationMs && steps < 5) { input.flush(sim); sim.step(1); acc -= sim.tickDurationMs; }`。
  **注入必须在 `step` 之前**——`inject` 对 `tick < sim.tick` 抛 `RangeError`，而 `step(1)` 处理的正是 `sim.tick`。
  **必须用 `sim.tickDurationMs`**，不得硬编码 16.67。溢出（`steps === 5`）时清空累加器，防螺旋死亡。
- **`PX_PER_UNIT = 10` 是渲染层唯一持有的常量契约**；`src/` 中不存在任何像素概念。
- **朝向不翻转符号**：`facingRadians` 是 atan2 约定，世界 y 直接映射屏幕 y（向下）时
  `container.rotation = facingRadians` 可直接用。
