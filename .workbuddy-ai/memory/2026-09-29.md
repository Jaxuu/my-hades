### 关键发现 2（P0 缺陷，已修）：尸体视图会被「复活」，死亡效果无限重播
**根因**：`createMissingViews` 只以 `world.query(TransformComponent)` 为依据建视图。但 M4-T02 铁律是
**尸体永不销毁**（spec 08 §4.4）⇒ 尸体仍 `isAlive`、仍有 `TransformComponent`
⇒ 死亡 FX 播完 `recycle` 删掉视图后，**下一帧立刻为这具尸体重建视图**，`syncTransforms` 又看到
`isDead` → `isDying = true` / `deathElapsedMs = 0` → FX 从头重播，周期 = `DEATH_FADE_MS`（400ms）**无限循环**。
表现：方块每 400ms 闪回一次，直接违反验收标准「打死方块后方块消失」。

**复现手法（值得复用）**：`pixi.js` 的**场景图对象（`Container` / `Graphics`）在 node 下可正常构造**，
不需要 jsdom、不需要真浏览器——只需给 `Application` 一个鸭子类型替身
`{ stage: new Container(), ticker: { deltaMS: 20, add(){}, remove(){} } }`，即可用真实 `GameSimulator` +
真实 `GameRenderer` 逐帧驱动并观测 `renderer.viewCount`。
缺陷签名极其清晰：`2,2,…,2,1,2,2,…,2,1`（每 20 帧 = 400ms/20ms 循环一次）。

**修法**：`GameRenderer` 引入 `private readonly retired = new Set<EntityId>()`，
`createMissingViews` 对退役 id `continue`；**只在「死亡 FX 播完」这条路径退役**
（`advanceDeaths` 里 `retired.add(id)` 再 `recycle`）。
**关键取舍**：`recycleDestroyed`（`destroyEntity`，如判定圆寿命耗尽）**不退役**——那条路径自纠正
（已销毁实体不再出现在 `query` 里），而万一将来 id 被复用，误退役会**永久隐藏一个合法实体**，是更糟的失败模式。
⇒ 该 `Set` 的安全性依赖 **`World.nextId` 单调递增、id 永不复用**这个不变式，注释里已写明。
修复后 60 帧序列收敛为 `2,…,2,1,1,1,…`。

### 工程要点
- **`vite` 被钉在 5.x**：不是随意选择——`vitest@2.1.8` 的 peerDependency 是 `vite ^5.0.0`，
  装 vite 8 会造成 peer 冲突。⇒ 未来升级 vitest 时才能一起升 vite。
- **`pixi.js` 是 8.21.0**，API 与 v7 差异极大：`await app.init({...})`、画布是 **`app.canvas`**（不是 `app.view`）、
  `Graphics` 是链式 API（`g.circle().fill().stroke()`，**没有** `beginFill/drawCircle/endFill`）。
- **根 `tsconfig.json` 不能塞 `client/`**（根 `lib` 只有 `ES2022`，无 DOM）；新建 `tsconfig.client.json`
  （`lib: [ES2022, DOM, DOM.Iterable]`，`noEmit`，strict 未关）+ `typecheck:client` 脚本。
- **`GameLoop` 时序**：累加真实 `deltaMS`，`while (acc >= sim.tickDurationMs && steps < 5) { input.flush(sim); sim.step(1); acc -= sim.tickDurationMs; }`。
  **注入必须在 `step` 之前**——`inject` 对 `tick < sim.tick` 抛 `RangeError`，而 `step(1)` 处理的正是 `sim.tick`。
  **必须用 `sim.tickDurationMs`**，不得硬编码 16.67。溢出（`steps === 5`）时清空累加器，防螺旋死亡。
- **`PX_PER_UNIT = 10` 是渲染层唯一持有的常量契约**；`src/` 中不存在任何像素概念。
- **朝向不翻转符号**：`facingRadians` 是 atan2 约定，世界 y 直接映射屏幕 y（向下）时
  `container.rotation = facingRadians` 可直接用。

### 新增铁律（M5-T02 起）
1. **管道现在是 14 段**：`TransformSnapshotSystem` 位于 **index 0**（先于 `PlayerControllerSystem`），
   其余 13 段相对顺序一字未改，`LifespanSystem` 仍 LAST。改管道会打断 **6 处钉桩**：
   `tests/combat/feedback.test.ts`、`tests/ai/enemy_fsm.test.ts`、`tests/combat/boons.test.ts`、
   `tests/combat/status_effects.test.ts`、`tests/combat/death_and_encounter.test.ts`（5 处 `toEqual` 名数组）
   + `enemy_fsm.test.ts` 的探针插入点。**探针插入点一律按名 `findIndex` 定位，禁硬编码索引。**
2. **`PreviousTransformComponent` 是「渲染支撑组件」**：只由 `TransformSnapshotSystem` 写、只由渲染层读，
   **任何玩法系统不得读或写**。丢弃它不改变模拟结果。它**惰性挂载**（首次见到实体以当前 Transform 播种），
   ⇒ `spawnCombatant` 的组件契约不需要改，运行中生成的判定圆也自动覆盖。
3. **插值语义**：`syncWorld(world, alpha)`，`alpha` clamp 到 `[0,1]`；
   `renderX = (prevX + (currX - prevX) * alpha) * PX_PER_UNIT`；rotation 走 `shortestArcDelta`（值域 **`[-π, π]` 两端都闭**，`-π ≡ π`）。
   **`alpha` 默认 `1`** 是刻意的向后兼容选择——`alpha = 1 ⇒ renderX = currX`，逐位等价 M5-T01，
   所以冻结的 `renderer_bridge.test.ts` 单参调用原样通过。
4. **`GameLoop` 的 alpha**：追帧 `while` 循环**之后**（累加器已扣减）算
   `alpha = clamp(accumulatorMs / tickDurationMs, 0, 1)`。累加器余数 = 已走进下一 Tick 的进度 = 插值系数。
   插值带来恒定 **+1 Tick（≈16.7ms）视觉延迟**，是 ADR-002 的显式取舍。
5. **`fxLayer` 必须是 root 的最后一个子节点**：`init()` 先挂 `fxLayer`，实体视图用
   `addChildAt(view, children.length - 1)` 插到它**之下** ⇒ FX 画在最上层，同时保住
   `root.children[0]/[1]` 升序实体视图的 M5-T01 冻结索引契约。**不要改成 `addChild`。**
6. **受击闪烁用 `tint`，不是新系统**：`isFrozen(world,id) || state === ActionState.HITSTUN` ⇒
   `container.tint = 0xff0000`，否则 `0xffffff`。PixiJS `tint` 是**乘法**、只能变暗/移色相，
   **无法"变白"**（白色恰是 NO_TINT）——所以选了纯红。判定圆无 State/Freeze ⇒ 不被染色。
   染色逻辑在 `syncTransforms` 的 `isDying` 提前 `continue` **之后**，不会与死亡 FX 抢 `tint`。
7. **伤害跳字**：`EntityView.lastHp` 在**视图创建时播种**（否则首帧误报）；每帧 `hp < lastHp` ⇒
   生成 `-(lastHp - hp)`，挂 `fxLayer`，`FLOATING_TEXT_LIFETIME_MS = 1000` 后销毁。
   HP **上升**（治疗）不得触发。跳字用真实帧时间推进，**不得回流逻辑层**。

### PixiJS v8 在纯 Node（无 DOM）下的实测行为（重要）
- `new Text({ text, style })` **可以构造成功**，`.text` / `.x` / `.y` / `.alpha` **可读**，
  是 `Container` 子类，`addChild` / `destroy()` 正常。
- ⚠️ **读 `.width` / `.height` / bounds 会抛 `document is not defined`**（惰性文本测量需要 canvas）。
  ⇒ 跳字断言**只能碰 `.text` / 坐标 / alpha / 父子关系**。
- ⚠️ `new Text(text, style)` 位置参数形式已废弃会打警告 ⇒ **必须用 `{ text, style }` 对象形式**。

  **没有 `renderer`** ⇒ 任何依赖真实渲染器的调用都会失败。
